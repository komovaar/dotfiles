# dotfiles

Personal Linux dotfiles for Firefox, tmux, and KDE Plasma.

- [Firefox](firefox/README.md): standard fonts for browser tabs and menus.
- [tmux](tmux/README.md): install the Paper theme with `./tmux/install.sh`.
- [KDE](desktop/kde/README.md): back up and restore desktop settings.
- [Paper](desktop/kde/paper/README.md): desktop and terminal appearance.

Generic serif, sans-serif, and monospace fonts use system defaults so browser
content does not inherit a forced desktop font.
